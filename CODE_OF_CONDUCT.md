# Code of Conduct

golduck follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be kind. Disagreements about code are fine; disagreements about people aren't.
- Assume good intent; ask before accusing.
- Harassment, discrimination, or personal attacks get you banned.

## Reporting

Report conduct issues by opening a private GitHub security advisory on the repo, or emailing the maintainers. Reports are handled confidentially.
